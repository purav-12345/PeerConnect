# 🎓 PeerConnect

## 🌟 Project Overview
PeerConnect is a comprehensive collaborative learning platform designed to enhance the educational experience by combining productivity tools with real-time peer interaction. It acts as a central hub where excellence meets companionship, providing students with everything they need to study effectively, communicate with peers, and stay updated on technological trends.

## 🚀 Core Features
*   **Collaborative Study Rooms:** Dedicated spaces equipped with video call functionality and chatrooms for seamless group work. Users can easily create or join video chats to interact in real-time.
*   **Live Document Editing:** Interactive collaborative document editing capabilities enable students to work on shared notes and projects live.
*   **Productivity Tools:** Built-in tools include Pomodoro timers to help users stay focused, along with to-do lists, calendars, and reminders to manage academic and extracurricular tasks.
*   **StudyGPT Integration:** An integrated AI assistant that enhances learning by providing prompt-based question responses, such as answering coding queries or historical tech facts.
*   **Centralized Resources:** A centralized repository for study materials, providing easy access to necessary resources like notes, PPTs, and previous papers. It also includes web-scraping functionality to compile relevant resources from the web, such as DSpace.
*   **Communities & Forums:** Users can join specialized communities—such as the Blockchain Developers Hub, Data Science Society, or Algorithm Wizards—to engage in discussions and share knowledge.
*   **Gamification Tracking:** The platform tracks user progress by awarding points, tracking levels, and maintaining study streaks to boost motivation.
*   **Tech Updates:** A dedicated section that provides regular tech-related news and updates.
*   **Secure Authentication:** Secure sign-in system powered by Clerk, allowing users to log in via GitHub, Google, or standard email/username.

## 🛠️ Tech Stack & APIs
PeerConnect is built on a modern, responsive stack utilizing powerful APIs for real-time collaboration:

*   **Frontend:** Built with **Next.js** for dynamic and responsive user interfaces.
*   **Backend:** Powered by **Node.js** and **Express.js**.
*   **Database:** Utilizes **MongoDB**, a flexible NoSQL database, for efficient data storage.
*   **Real-Time Communication:** Integrates the **LiveBlocks API** for real-time chat functionality and document editing, alongside **ZegoCloud's API** for enhanced video chat experiences.
*   **Document Storage:** Facilitated by **Google Cloud Platform APIs** for robust document management and storage.
*   **AI Integration:** Leverages **Gemini AI** to power the StudyGPT prompt-based learning enhancement.
*   **News Integration:** Uses a **News API** to fetch and display recent tech updates.

## 🔮 Future Scope (Roadmap)
As PeerConnect grows, the following features are planned to expand its capabilities:
*   Integration of deeper gamification elements to further enhance user motivation and engagement.
*   Introduction of augmented reality (AR) features to provide highly interactive learning experiences.
*   Implementation of voice-enabled search and navigation to improve platform accessibility.
*   Integration of blockchain technology to facilitate secure credentialing and verification.
*   Expansion of partnerships with educational institutions to broaden the available content and resource access.
*   Development of dedicated mobile applications to support on-the-go learning and accessibility.
